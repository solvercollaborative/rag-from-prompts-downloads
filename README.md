# Local-first RAG and GraphRAG from Prompts: Course 1 downloads

Companion materials for **Build Your First Web App with OpenAI Codex on Mac**
by Alan Street / Solver Collaborative.

Turn a book into a question-answering tool in 15 guided prompts. The illustrated
book explains the concepts and steps; these matching materials give your coding
assistant the editable designs, prompts and searchable student-edition text.

## Start with your book

Current Mac + Codex materials: **workshop-draft-0.81-codex**, book version **0.81**.
Use the exact edition printed in your book. In **Get your workshop downloads**,
copy the download prompt into Codex. It includes this repository, the exact
edition and the materials passphrase. Codex downloads and checks the materials,
preserves existing work, and stops before Lesson 00 so you can read it first.

You do not need a GitHub account, Git or project Python for the download step.
The course prepares the application tools in Lesson 01. Keep the illustrated
book open as your reading guide; the materials package is a small text export
and does not include another PDF.

## What the materials contain

The encrypted package contains 46 files: fifteen action prompts, editable
designs, a glossary, the complete searchable text of this student edition,
verified security helpers, file fingerprints and source/version information.
The lessons guide your coding assistant to create the application. Models and
the local search index are prepared during the course.

Your coding assistant follows the selected edition's release manifest and
[edition-specific setup](course-01/workshop-draft-0.81-codex/SETUP.md).
Published directories and their `course-01-<edition>` tags stay available for
books that name an earlier edition. Preserve an existing project when starting
a different edition.

## Access

Packages use [age passphrase encryption](https://github.com/FiloSottile/age).
The passphrase is supplied in the book. This public repository contains the
encrypted materials, setup instructions and release manifests; keep decrypted
course text and personal project data in your local project.
